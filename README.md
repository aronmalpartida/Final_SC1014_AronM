# Final_SC1014_AronM
1 . Descripción: Un resumen de qué hace tu programa.
Mi programa ayuda a convertir coordenadas utm a coordenadas geograficas , ingresando manualmente las variables que lleva una coordenada y al final te da un documento csv con los resultaos 

2. Instrucciones de Compilación: Qué comandos usar para ejecutarlo.
En CLion solo presiono el botón de Run ,  y el IDE lo compila y ejecuta automáticamente.
